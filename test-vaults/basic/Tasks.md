# Task states

- [ ] pending
- [x] done
- [X] done, capital X
- [-] cancelled, a community convention
- [/] in progress, a community convention
    - [ ] nested pending, indented under the previous one
- [ ] task that links to [[Alpha]]

> - [ ] task inside a blockquote

```text
- [ ] task inside a fenced code block, must not be indexed
```

- ordinary list item, not a task
