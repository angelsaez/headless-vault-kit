# Writing about Kanban

This note explains the format. The plugin marks a board with a line in its frontmatter:

```yaml
kanban-plugin: board
```

That line is in a code fence and in the body, not in this note's own frontmatter, so this note
is a note. A parser that searched the whole file would index the example below as a real card.
